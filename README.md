# Donat NS - Sistem Informasi Laporan Penjualan & Distribusi

Project ini adalah aplikasi web PHP/MySQL untuk sistem laporan penjualan dan distribusi Donat NS.

## Fitur
- Sistem login admin
- Manajemen warung
- Stok harian
- Distribusi donat
- Pengambilan BS dan hasil penjualan
- Setoran sales
- Dashboard ringkasan
- Laporan harian/mingguan/bulanan
- Grafik Chart.js

## Langkah awal
1. Pastikan XAMPP aktif dengan Apache dan MySQL.
2. Letakkan folder project di `C:\xampp\htdocs\laporan-penjualan-umkm`
3. Buka `http://localhost/laporan-penjualan-umkm/`
4. Login dengan:
   - username: `admin`
   - password: `admin123`

## Catatan
- Database default: `donat_ns`
- User DB default: `root` / password kosong
